## Doutes pour un prof

1. **`4eme/dire-l-amour` `flashcards[7].front`.** « Quel thème relie le refrain du « Pont Mirabeau » d'Apollinaire ? » est mal construit : « relier » demande deux termes (relier les strophes et le refrain, par exemple). Je n'ai pas remplacé le verbe par « exprime », parce que le verso parle de « l'amour qui passe comme l'eau de la Seine », qui est dans les strophes (« L'amour s'en va comme cette eau courante »), alors que le refrain dit le temps qui passe et le poète qui demeure. La bonne reformulation dépend de ce que la carte veut faire retenir.
2. **`4eme/relatives-et-conjonctives` `flashcards[6].back` et `resume.sections[4].content`.** « La conjonction suit un verbe » est vrai pour la complétive, mais pas pour le « que » de la conséquence vue dans le même chapitre (« si fatigué qu'il… », « tellement que »). Le test donné ensuite (chercher un antécédent) reste juste dans tous les cas ; non modifié.
3. **`4eme/la-fiction-pour-interroger-le-reel` `flashcards[3].back`.** « La rivière de diamants perdue, que Mathilde a remboursée pendant dix ans » est un raccourci : Mathilde rembourse les dettes contractées pour acheter une rivière de remplacement, comme le dit `resume.sections[0].exemple`. Compréhensible, non modifié.
4. **`4eme/informer-s-informer-deformer` `quiz[5].explanation`.** Le choix parle de « j'aime », l'explication de « partages ». Les deux vont dans le même sens ; non modifié.
